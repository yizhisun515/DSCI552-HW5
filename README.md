- Python 3
- NumPy
- pandas
- Matplotlib

## Usage

1. Install the required dependencies:

   `pip install -r requirements.txt`

2. Open `notebook/Sun_Yizhi_HW5.ipynb` in JupyterLab.
3. Run all cells sequentially.
